Sort images

Pick a folder of images and swipe through them. Each yes or no moves the image into a yes or no folder inside it. Undo moves it back.

This browser can't open a folder. Use Chrome or Edge on a Mac or Windows PC.

Reopening the same folder picks up where you left off: anything already in yes or no is not shown again.

Folders & keys

Each folder is a button and a key. Its name is the folder that images are moved into. Renaming a folder doesn't move anything already sorted. Click a key, then press the new key. Esc cancels.
