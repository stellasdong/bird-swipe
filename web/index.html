bird-swipe

Swipe through Macaulay Library nest media and label it fast. Open your export, label it, then save the finished file to your folder in the shared project. Nothing is uploaded anywhere else.

This browser can't open a folder.
bird-swipe needs Chrome or Edge on a Mac or Windows PC. Safari and Firefox don't support writing to a local folder, so labels couldn't be saved.

Recorded in the reviewer column so labels can be traced back to you.

Local folder

A copy on this computer, written as you label. Without one, your work is kept only in this browser.

OneDrive folder

Your folder in the shared project, so finished spreadsheets reach the rest of the team.

Both are optional. You can open a spreadsheet, label it, and save it to your computer without ever setting up OneDrive.

    Set up your OneDrive folder
    
  
    
    bird-swipe saves into a folder on this computer. OneDrive is what carries it
    up to the shared project. Do this once:
  
    
  
      
    
    1. Install OneDrive and sign in with your university account.
      2. 
    
    2. Open the shared project link in a browser and click
        Add shortcut to My files (or right-click the folder under
        Shared in OneDrive). Ask Mei for the link.
      3. 
    
    3. Wait for it to sync. In Finder it appears under
        OneDrive – <Your University>; on Windows, under
        This PC → OneDrive – <Your University>.
      4. 
    
    4. Find your own subfolder inside the project folder — make one if
        it isn't there yet, and check with Mei what to call it.
      5. 
    
    5. Right-click your folder → Always keep on this device, so files
        aren't left in the cloud only.
      6. 
  
    
  
    
    Pick your own subfolder, not the project folder above it — everyone's
    folders sit side by side and bird-swipe can only show you the folder's name.
  
    
  
    
    Stuck, or don't have a folder yet? The project
    protocol covers this step in full, and Mei can set you up.
    You can carry on without OneDrive in the meantime — label as normal and use
    Save local.
