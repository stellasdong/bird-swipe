bird-swipe

Swipe through Macaulay Library nest media and label it fast. Open your export, label it, then send the finished file to the shared SharePoint folder. Nothing is uploaded anywhere else.

This browser can't open a folder.
bird-swipe needs Chrome or Edge on a Mac or Windows PC. Safari and Firefox don't support writing to a local folder, so labels couldn't be saved.

Recorded in the reviewer column so labels can be traced back to you.

Choose a local folder to save into?
While you label, your work is kept in this browser. Pick a folder and bird-swipe will also keep a copy of it on disk as you go — worth doing if you'd rather not rely on browser storage alone.

    Set up your OneDrive folder

    bird-swipe saves into a folder on this computer. OneDrive is what carries it up to the shared project. Do this once:

    1. Install OneDrive and sign in with your university account.
    2. Open the shared project link in a browser and click Add shortcut to My files (or right-click the folder under Shared in OneDrive). Ask the project lead for the link.
    3. Wait for it to sync. In Finder it appears under OneDrive – <Your University>; on Windows, under This PC → OneDrive – <Your University>.
    4. Find your own subfolder inside the project folder — make one if it isn't there yet, and check with the project lead what to call it.
    5. Right-click your folder → Always keep on this device, so files aren't left in the cloud only.
    Pick your own subfolder, not the project folder above it — everyone's folders sit side by side and bird-swipe can only show you the folder's name.
